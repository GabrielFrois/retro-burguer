# Retro Burger

Uma Landing Page completa e responsiva desenvolvida para uma hamburgueria artesanal fictícia. O projeto foca em design moderno, navegação intuitiva e conversão de clientes através de links diretos para WhatsApp e Maps.

## Preview

![Preview](/src/img/preview.png)

## Funcionalidades

- **Design Responsivo:** Layout adaptável para Desktops, Tablets e Smartphones.
- **Menu de Navegação Fixo:** Com rolagem suave (Smooth Scroll) entre as seções.
- **Cardápio Visual:** Grid interativo com fotos e preços dos lanches.
- **Chamadas para Ação (CTA):**
  - Botão de "Peça Agora" integrado diretamente com a **API do WhatsApp**.
  - Botão de "Venha nos Visitar" integrado com o **Google Maps**.
- **Menu Mobile:** Menu hambúrguer animado para dispositivos móveis.

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
  - Flexbox & CSS Grid
  - Variáveis CSS (:root)
  - Media Queries para responsividade
- **JavaScript**
  - Manipulação do DOM para o menu mobile
- **Font Awesome**
- **Google Fonts** 
  - Fontes 'Lato' e 'Pacifico'

## Como executar o projeto
1. Faça o clone deste repositório:
```Bash
git clone https://github.com/GabrielFrois/retro-burguer.git
```
2. Navegue até a pasta do projeto.
3. Abra o arquivo index.html no seu navegador de preferência.
